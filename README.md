# MeetMind AI — Chrome Extension UI Preview

This folder contains a visual prototype so you can see the popup and side panel design.

## Load in Chrome
1. Extract the ZIP file.
2. Open `chrome://extensions`.
3. Turn on **Developer mode**.
4. Click **Load unpacked**.
5. Select the extracted `meetmind-ai-preview` folder.
6. Click the MeetMind AI extension icon to open the popup.
7. Use Chrome's side panel control to open the extension side panel if the popup button cannot open it on the current tab.

## What works in this preview
- Popup and side panel UI.
- Tabs for Copilot, Transcript and Notes.
- Demo-only sample conversation.
- Copy sample reply/question.
- Export sample notes as a `.txt` file.
- Demo session button.

## Not implemented yet
- No Zoom audio is captured.
- No live transcription.
- No real AI calls.
- No cloud sync or persistent meeting archive.

All sample transcript and AI suggestion text is fictional placeholder content. This is a UI preview, not a working meeting recorder.
